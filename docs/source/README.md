# `source` — Rohmaterial und Auszüge

Ablage für **Ausgangsmaterial**, das noch nicht zu einem unserer Dokumente verarbeitet ist:
Mitschnitte, Auszüge aus fremden Quellen, Messprotokolle, Recherche-Ergebnisse.

## Regeln

- Hier liegt **unbearbeitetes** Material. Sobald etwas ausgewertet ist, wandert die
  Erkenntnis in ein Dokument im [Katalog](../INDEX.md) — und die Herkunft wird dort genannt.
- Nichts hier ist eine Aussage des Projekts. Kein Dokument verlinkt `source/` als Beleg für
  eine Entscheidung, ohne den Auszug zu prüfen.
- Große Binärdateien gehören hier nur abgelegt, wenn sie zur Nachprüfbarkeit nötig sind.

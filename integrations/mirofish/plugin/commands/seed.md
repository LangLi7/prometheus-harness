# Seed für MiroFish bauen

```bash
bun "$DSH_HOME/plugins/mirofish/mirofish/scripts/mirofish.mjs" seed <ordner|url> --out mirofish-seed.md
```

Danach das erzeugte Dokument **bearbeiten**, nicht unverändert hochladen:

1. Drei Zielgruppen-Segmente mit Motivation, Einwand und typischer Sprache.
2. Ein Hauptversprechen, drei Beweise, ein Preis.
3. Größter Preiseinwand und die stärkste Alternative (auch „nichts tun").
4. Sechs Prognosefragen prüfen; pro Projekt anpassen.

Regeln: unter 9.000 Zeichen, keine Personendaten, keine internen Dokumente,
keine Kundenmails. Der Seed ist Marketingmaterial, das an einen fremden Dienst
geht — behandle ihn so.

Nenne am Ende den Pfad und die Zeichenzahl.

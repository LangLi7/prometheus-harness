# Report auswerten

Der Report ist eine Meinungssammlung aus einer Simulation, keine Messung.

Lies ihn und beantworte knapp:

1. **Erster Eindruck** in einem Satz, in der Sprache der Zielgruppe.
2. **Geglaubtes Versprechen** und **unglaubwürdiges Versprechen**.
3. **Top-3-Einwände** in der Reihenfolge, in der sie auftauchen.
4. **Preiswahrnehmung**: teuer, fair, billig — und wodurch.
5. **Teilbare Botschaft**: welche Formulierung würde in einem Feed überleben?
6. **Drei Änderungen**, die den stärksten Einwand entkräften.
7. **Drei Änderungen**, die Vertrauen erhöhen.

Übernimm nur, was eine Design-Entscheidung ändert. Schreibe das Ergebnis in
`design.md` §7 (Offene Entscheidungen) oder in eine Projektnotiz — mit dem
Hinweis „synthetische Simulation, keine echten Nutzer".

Keine erfundenen Zitate. Wenn der Report keine Antwort auf eine Frage enthält,
schreibe „nicht beantwortet" statt zu interpolieren.
